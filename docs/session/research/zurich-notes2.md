## Outcomes per gap
1. **Green roofs / green space**: no roof-greening dataset (CKAN search "Dachbegrünung" → only 2010 CIR/NDVI orthophotos, "Gründach" → 0). The Biotoptypenkartierung 2020 has `Flachdach` types but only 25 polygons, 0.52 ha, against ~1,119 ha of "Gebäude" polygons → not a roof inventory. Note: derivable in principle from the CC0 2010 CIR/NDVI orthophotos or the LoD2 roof model + CHM, not done.
2. **Sealing**: no published city statistic. New derived figure `zurich.context.05`: biotope map 2020, attribute `VERSIEGELUNG` (publisher: "Beeinträchtigung der natürlichen Bodenfunktion des Biotoptyps"). WFS paged (96,178 polygons, 11 null geometries), planar area in EPSG:2056, 91.79 km² of the city total 91.88 km² (BEV580OD5803, 9188.1 ha): unversiegelt 65.62 %, teilweise 4.66 %, versiegelt 28.59 %, unbekannt 1.13 %. Denominator includes forest (21.4 km², all unsealed) and water (5.2 km²). Extra, not in profile: excluding forest and water the sealed share is 26.24 / 65.2 = 40.3 %. Not comparable with the cantonal 14 % (Arealstatistik) nor with Basel (cadastral land cover): the measure block states method and scale. Origin `derived`, explicitly this project's computation. Reproduce: `node scripts/maps/zurich.mjs --only=sealstats`. Layer `zurich.sealing.01`: Hardplatz window (966 polygons intersect, 727 kept after clipping and 4 m simplification), `measure_topic: sealing-fraction`.
3. **Sewer**: no open sewer geodata (CKAN searches Kanalisation, Kanalnetz, Entwässerung, Abwasser, Siedlungsentwässerung). Text figures now found and quoted in `context.04` (id kept, state `no_public_evidence_found` → `found`): ERZ pages "rund 1000 Kilometer" (two pages), 104 km walkable, "rund 80 Prozent" combined system; the Umweltbericht 2025 says 1500 km (conflict kept, not resolved). The ERZ brochure PDF is still 404 and has no Wayback capture, so the 920 km figure from a search summary was NOT used. Gap `water` added.
4. **Canopy**: no city-level crown share beyond the existing 15 % (2022) / 17 % (2018) entry. New `measurement.05`: the city CHM 2022 (lidar class 5, vegetation >3 m, 50 cm grid, highest height per cell, gaps <2 m² interpolated) is the stated basis "für die Kronenbedeckung". The TIFF link returns an HTML page, so no own computation. `measurement.01` method extended: threshold not stated on the quoted page, Basel's threshold not stated either → definitions not claimed equal (still topic `canopy`, scale text differs, so renders "not comparable"). Gap `trees` added.
5. **Heavy rain**: the cantonal Oberflächenabfluss is an open CC0 dataset with WFS (maps.zh.ch/wfs/OGDZHWFS, typenames `ogd-0035_awel_wb_ofa_fliesstiefen_p{30,100,300,1000}_f`). Unclipped Hardplatz window is 17–20 MB, so: one return period (P100), clipped to the window and simplified → 191 KB, `zurich.pluvial.01`, origin `modelled`. City-wide and other events stay a gap (rewritten). `measurement.03` updated with the CCZero licence source.
6. **Extra**: `measurement.06` Überschwemmungsmeldungen CSV (observed, CC0): 3,684 reports / 2,496 rows, 1976-06-10 to 2025-11-09, 211 statistical zones (`stznr` = Statistische Zone where the event took place, per the dataset page); dataset says cause is very often unknown; no trend claim made (reporting behaviour unknown).
