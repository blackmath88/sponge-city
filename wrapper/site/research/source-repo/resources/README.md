# Resources

This directory is for reusable external references and a compact machine-readable catalogue.

- [`catalog.yml`](catalog.yml) — datasets, official references, technical standards and prior-art repositories.
- Human-oriented context lives in [`docs/`](../docs/README.md).

The catalogue intentionally mixes **verified** and **to-verify** leads. Check the `status` field before treating an entry as authoritative.
