# Evidence atlas

**Question:** What do we actually know about VoltaNord and Basel's sponge-city decisions, and what is still open?

Searchable facts, boundaries, open questions, actors, decision routes and the monitoring maturity ladder. Every record has a status (verified, inference, unknown, conflict, proposal) and sources.

- Page source: `page.html` → built to `site/evidence-atlas.html`
- Data: `data/evidence-atlas.json` (schema `data/evidence-atlas.schema.json`), shared with every other solution
- Test: `smoke.mjs`; data checks in `scripts/validate-atlas.mjs`
- Background: [QUERYABLE-EVIDENCE-ATLAS.md](../../docs/QUERYABLE-EVIDENCE-ATLAS.md), [MONITORING-DATA-STACK.md](../../docs/MONITORING-DATA-STACK.md)
